# Fonts

Self-hosted copies of the Google Fonts the game uses, so the game makes no requests to other sites and the fonts are stored for offline play. Only the Latin and Latin Extended subsets are included.

| File | Font | Licence |
|---|---|---|
| `luckiest-guy-*.woff2` | Luckiest Guy by Astigmatic | Apache License 2.0 |
| `nunito-*.woff2` | Nunito by Vernon Adams, Cyreal and Jacques Le Bailly (variable, weights 700 to 900 used) | SIL Open Font License 1.1 |
